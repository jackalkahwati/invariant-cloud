# Invariant Launch Sequence

Execute in this order. Don't skip steps — each one builds on the last.

---

## Week 1 — Foundation

**Day 1 (today)**
- [ ] Post Show HN (Tuesday or Wednesday 9-11am ET for max visibility)
- [ ] Be online for 2 hours after posting to reply to every comment
- [ ] After HN hits 10+ upvotes, post the Twitter thread
- [ ] Share HN link in Latent Space Discord and LangChain Discord

**Day 2-3**
- [ ] Post blog post to dev.to and Substack (or invariant.me/blog if you set one up)
- [ ] Send 3-5 of the DMs from the outreach list (Harrison Chase, Jerry Liu, Yohei)
- [ ] Post in r/MachineLearning (technical framing, not a pitch)

**Day 4-5**
- [ ] Send remaining DMs
- [ ] Post in r/LocalLLaMA and r/LangChain
- [ ] Post standalone tweets A and B from the Twitter thread doc

---

## Week 2 — Follow-up

- [ ] Follow up with anyone who replied to DMs — offer a 15-min call
- [ ] Post tweet C if you have early user feedback
- [ ] Write a short follow-up HN comment on your own thread with usage stats
- [ ] Apply to post in YC's Bookface if you have YC connections

---

## Week 3+ — Compound

- [ ] If any DM target responds positively, ask for a public quote or retweet
- [ ] If HN post did well, write a follow-up post: "What we learned from our first 100 users"
- [ ] Reach out to AI newsletters: The Rundown, TLDR AI, Ben's Bites — offer a guest write-up

---

## Metrics to track

| Metric | Target (30 days) |
|--------|-----------------|
| HN upvotes | 100+ |
| Signups from HN | 200+ |
| GitHub stars (invariant-cloud) | 100+ |
| DM responses | 3+ |
| Paying customers | 3+ |

---

## The one thing

If you only do one thing from this entire plan: **post the Show HN**.

The HN community is exactly your buyer — technical, building agents, willing to try new infrastructure. One good HN post can outperform months of other marketing.

Everything else amplifies that.
